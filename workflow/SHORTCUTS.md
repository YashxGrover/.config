# Workflow app shortcuts

Hold Right Option with all listed keys together.

## Navigation

| Keys | Action |
|---|---|
| Right Option + 1–4 | Switch macOS desktop (Study, Browse, Create, Personal) |
| Right Option + Shift + 1–4 | Move focused window to that desktop and follow |
| Right Option + Q + 1–4 | Move focused window to that desktop; stay here |
| Right Option + Shift + E | Open theme menu |
| Right Option + W/A/S/D | Focus window up/left/down/right |
| Right Option + Left/Right Arrow | Previous/next window in Monocle |
| Control + Option + two-finger scroll | Pan focus with the trackpad (KiwiDesk built-in) |
| Right Option + Shift + W/A/S/D | Swap window up/left/down/right |
| Right Option + Control + W/A/S/D | Resize window up/left/down/right |
| Right Option + Return | Toggle maximize |
| Right Option + Backspace | Pocket or restore window |
| Right Option + Shift + Space | Toggle floating |

Desktops 1–5 use Monocle; desktop 6 uses BSP. Each has one KiwiDesk Space.
